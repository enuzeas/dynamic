# 쌤쌤 — 데이터 촬영 현장 체크리스트

> 목적: 개인 움직임 지문(bio-signature) 추출용 모션 데이터 수집
> 1인당 소요: **약 15분** (세팅 5분 + 촬영 10분)
> 목표 규모: **참가자 15~20명 × 6동작 × 3테이크 × 카메라 2대**

---

## 0. 촬영 전날 준비

- [ ] 카메라 2대 충전 (정면용 / 45도용)
- [ ] 삼각대 2개, 바닥 표시 테이프
- [ ] 동의서 인쇄 (참가자 수 + 여유분)
- [ ] 참가자 ID 라벨 준비 (P001, P002 …)
- [ ] 촬영 공간 확보 — **직선 6m 이상** 확보 필요 (걷기 왕복)
- [ ] 배경 정리: 단순한 벽, 움직이는 물체 없음
- [ ] 조명 균일화 (역광 금지, 창문 등지지 않기)

---

## 1. 장비 세팅

### 카메라 배치

```
                    [벽 / 단순 배경]

        ●────────────── 6m ──────────────●
      시작점                            반환점

              ┌──────┐        ┌──────┐
              │ CAM-F│        │ CAM-D│
              │ 정면 │        │ 45도 │
              └──────┘        └──────┘
                  4~5m 거리, 높이 1.2m
```

- [ ] **CAM-F (정면)**: 동선 정중앙 정면, 높이 약 1.2m (허리 높이)
- [ ] **CAM-D (45도)**: 정면에서 45도 측면, 같은 높이
- [ ] 두 카메라 **동시 녹화** — 검증용 교차 카메라 데이터 확보

### 카메라 설정 (양쪽 동일하게)

- [ ] **60fps** 고정 ← 조깅 모션 블러 방지, 30fps 금지
- [ ] 해상도 1080p 이상
- [ ] **자동 초점 OFF** (수동 고정) — 오토포커스 헌팅 방지
- [ ] 손떨림 보정 **OFF** — 프레임 좌표계가 흔들리면 정규화가 깨짐
- [ ] 전신이 프레임에 **여유 있게** 들어오는지 확인 (머리 위·발 아래 여백)
- [ ] 테스트 촬영 1회 → 재생 확인

### 동기화

- [ ] 각 테이크 시작 전 **박수 1회** (오디오 파형으로 두 카메라 싱크)

## 2. 참가자 접수

- [ ] 동의서 서명 수령 (수집·저장·적용·상업이용 **각 항목 개별 체크** 확인)
- [ ] 참가자 ID 부여 — **실명은 촬영 파일·메타데이터에 절대 기록 금지**
- [ ] 실명↔ID 대응표는 **별도 파일·별도 보관**

### 복장 확인 (미충족 시 촬영 연기)

- [ ] 헐렁한 옷 ✕ — 관절 추정 붕괴. 몸선이 보이는 복장
- [ ] 치마·긴 코트 ✕
- [ ] 모자·후드 ✕ (머리 랜드마크 가림)
- [ ] 신발 착용 — **세션 내내 동일한 신발**. 종류를 메타데이터에 기록
- [ ] 배경과 비슷한 색상 옷 ✕ (분리 실패)

## 3. 촬영 동작 6종

| # | 동작 | 길이 | 테이크 |
|---|---|---|---|
| 1 | **자연 걷기** — 왕복 2회 | 10초 | 4회 (첫 회 폐기) |
| 3 | **설명하며 말하기** — 주제 1개 | 20초 | 4회 (첫 회 폐기) |
| 4 | **앉았다 일어서기** ×3 | 15초 | 4회 (첫 회 폐기) |
| 5 | **제자리 뛰기** | 10초 | 4회 (첫 회 폐기) |
| 2 | **조깅** — 같은 경로 | 8초 | 3세트 (전량 사용) |
| 6 | **지친 걷기** — 조깅 직후 즉시 | 10초 | 3세트 (전량 사용) |

> **첫 테이크 폐기 원칙**: 첫 회는 어색함이 지배 → 4회 찍고 뒤 3회 사용
> **예외**: 조깅·지친걷기는 피로 누적 때문에 3세트만, 전량 사용

### 순서 규칙

- **① 2·6번 블록(조깅→지친걷기)은 항상 맨 마지막**
  → 피로가 다른 동작에 번지는 것을 방지
- **② 나머지 4종(1·3·4·5)은 참가자마다 순서를 바꿈**
  → 모두가 같은 순서면 '긴장'이 특정 동작에 공통으로 실려 스타일로 오인됨

**순서 로테이션표** (참가자 ID 끝자리로 배정)

| 패턴 | 끝자리 | 1st | 2nd | 3rd | 4th | 마지막 |
|---|---|---|---|---|---|---|
| A | 1, 5, 9 | 1 걷기 | 3 제스처 | 4 앉기 | 5 뛰기 | **2→6** |
| B | 2, 6, 0 | 3 제스처 | 4 앉기 | 5 뛰기 | 1 걷기 | **2→6** |
| C | 3, 7 | 4 앉기 | 5 뛰기 | 1 걷기 | 3 제스처 | **2→6** |
| D | 4, 8 | 5 뛰기 | 1 걷기 | 3 제스처 | 4 앉기 | **2→6** |

## 4. 참가자 안내 스크립트

### ⛔ 절대 금지

> **동작을 시연하지 마세요.**
> 촬영자가 "이렇게 하시면 돼요" 하고 보여주는 순간, 참가자는 촬영자를 따라 합니다.
> 그러면 추출되는 것은 참가자의 스타일이 아니라 **촬영자의 스타일**이며, 데이터 전체가 오염됩니다.
>
> **방식(how)을 지시하지 마세요.** 목표(what)만 말합니다.
> 방식을 지시하면 모든 참가자가 같은 방식으로 수렴해 개인차가 사라집니다.

| ✅ 이렇게 | ❌ 이렇게는 금지 |
|---|---|
| "저 표시까지 편하게 걸어가세요" | "팔을 자연스럽게 흔들면서 일정한 속도로" |
| "의자에 앉았다 일어나시면 됩니다" | "손으로 무릎 짚지 마시고 허리를 곧게" |
| "제자리에서 뛰어주세요" | "양팔을 위아래로 흔들면서" |

### 도입 안내 (그대로 읽기)

> "지금부터 몇 가지 간단한 동작을 촬영합니다. **정답이나 잘하는 방법은 없습니다.**
> 평소에 하시던 대로 편하게 해주시면 됩니다. 오히려 신경 써서 예쁘게 하시면 데이터가 못 쓰게 됩니다.
> 같은 동작을 3~4번 반복하는데, 매번 똑같이 하려고 애쓰지 않으셔도 됩니다."

### 동작별 지시문

**1. 자연 걷기**
> "저기 표시된 곳까지 걸어갔다가 돌아오세요. 그걸 두 번 반복합니다. 평소 걷는 대로요."

**3. 설명하며 말하기**
> "오늘 아침에 뭐 하셨는지 20초 정도 이야기해 주세요. 카메라 말고 저를 보고 말씀하시면 됩니다."
> - 주제 예비안: 최근 본 영화 / 집에서 여기까지 오는 길 / 주말 계획
> - 손을 쓰라고 **지시하지 말 것** — 안 쓰는 것도 그 사람의 스타일

**4. 앉았다 일어서기**
> "의자에 앉았다 일어나기를 세 번 해주세요."
> - 등받이 없는 의자, 팔걸이 없음

**5. 제자리 뛰기**
> "제자리에서 10초 정도 뛰어주세요."

**2. 조깅**
> "아까 걸으셨던 그 경로를 이번엔 가볍게 뛰어서 갔다 오세요."

**6. 지친 걷기** — 조깅 직후 **쉬지 않고 즉시**
> "네, 바로 다시 걸어서 갔다 와주세요."
> - ⚠️ "지친 것처럼 걸어주세요"라고 **절대 말하지 말 것** → 연기 스타일이 뽑힘
> - 실제 조깅 직후의 진짜 피로 상태를 촬영하는 것이 목적

## 7. 촬영 직후 품질 검사 (참가자 귀가 전!)

각 참가자 촬영이 끝나면 **그 자리에서** 확인합니다. 문제가 있으면 즉시 재촬영.

- [ ] 전 테이크에서 **전신이 프레임 밖으로 나가지 않았는가**
- [ ] 모션 블러로 팔다리가 뭉개진 구간 없는가 (특히 조깅)
- [ ] 프레임 드랍 없는가 (재생 시 끊김)
- [ ] 두 카메라 모두 정상 녹화되었는가 ← **가장 흔한 사고**
- [ ] 박수 싱크 신호가 양쪽에 들어갔는가
- [ ] 다른 사람이 프레임에 들어온 구간 없는가
- [ ] 파일 개수 확인: **정상 시 1인당 42개**
  (M01/03/04/05 × 4테이크 + M02/06 × 3세트 = 22테이크 × 2카메라 = 44 → 첫테이크 폐기 후 사용분 36개)

### MediaPipe 스팟 체크 (권장, 당일 저녁)

- [ ] 참가자별 1개 테이크를 MediaPipe에 통과시켜 관절 신뢰도 확인
- [ ] 평균 visibility가 낮으면 → 복장·조명 문제. 다음 참가자부터 조건 수정

## 8. 재촬영 세션 (S2) — 지문 검증의 핵심

> **참가자 중 5명은 1~2주 뒤 같은 프로토콜로 다시 촬영합니다.**

- [ ] 대상자 5명 선정 및 재방문 일정 확보 (1차 촬영 당일에 미리 약속)
- [ ] **의도적으로 조건을 바꿀 것**: 다른 날, 다른 옷, 다른 시간대
- [ ] 신발은 같은 것 / 다른 것 둘 다 있으면 더 좋음 (메타데이터에 기록)

**왜 하는가**: 여기서 지문이 유지되면 "그 사람의 움직임 지문"이라고 말할 수 있습니다.
유지되지 않으면 그날의 컨디션과 촬영 환경을 측정한 것에 불과합니다.
발표에서 이 결과 하나가 나머지 전부보다 설득력 있습니다.

| 항목 | 목표 | 현재 |
|---|---|---|
| 참가자 수 | 15~20명 (최소 10명) | ☐ |
| 동작 종류 | 6종 | ☐ |
| 총 클립 수 | 약 540~720 (카메라 2대 기준) | ☐ |
| 재촬영(S2) 인원 | 5명 | ☐ |

> **사람 수가 동작 수보다 중요합니다.** 사람 간 분산을 추정해야 '개인 성분'이 정의되므로,
> 한 명을 깊게 찍는 것보다 여러 명을 확보하는 것이 우선입니다.

## 10. 분석 단계 유의사항 (촬영팀 → 개발팀 전달)

- **LOMO 평가 시 주의**: 6종 중 1·2·6번이 모두 이동 계열입니다.
  6번(지친 걷기)만 빼고 평가하면 걷기가 학습에 남아 있어 **쉬운 시험**이 됩니다.
  → **3번(제스처) 또는 4번(앉았다 일어서기)을 제외한 조건**을 반드시 함께 보고할 것.
- **교차 카메라 검증**: CAM-F로 만든 지문이 CAM-D 영상에서도 유지되는지 확인.
  유지되지 않으면 그것은 사람이 아니라 촬영 각도의 지문입니다.
- **동작 기여도 분석**: 데이터가 모이면 동작을 하나씩 제외하며 재식별 정확도 변화를 측정.
  기여도 낮은 동작은 제품 등록 절차에서 제외 → "쌤쌤 등록에 필요한 최소 동작"이 도출됩니다.
