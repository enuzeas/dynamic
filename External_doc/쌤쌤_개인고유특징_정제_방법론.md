# 개인 고유 특징 정제 방법론 「쌤쌤」

> 해결 대상: 기획서 고려사항 #1 — *"동작-종속 변이와 개인 고유 성분을 어떤 통계적/알고리즘적 기준으로 분리할지 방법론 부재"*
> 이 문서는 그 분리 기준을 **분산 성분 분해(variance decomposition)** 로 정의하고, 정제·검증까지의 전체 절차를 규정한다.

---

## 0. 한 줄 요약

**"개인 고유 성분"을 통계 모델의 *사람 효과(person effect)* 로 정의하고, "동작-종속 변이"를 *동작 효과(motion effect)* 로 정의한다. 이 둘을 분산 성분 분해로 분리하며, 그 분해는 이미 채택한 ICC와 동일한 수식 위에 있다 — 따라서 정의·정제·검증이 하나의 통계 틀로 통일된다.**

---

## 1. 문제의 재정의

Motion Puzzle은 한 동작 샘플에서 신체 부위별 스타일 벡터를 뽑아준다. 그러나 이 벡터에는

- 그 **동작 종류이면 누구에게나** 나타나는 성분 (예: 뛰기라서 팔이 크게 흔들림), 그리고
- 그 **사람이라서** 나타나는 성분 (예: 이 사람은 무슨 동작을 하든 어깨가 앞으로 말림)

이 뒤섞여 있다. 지금까지는 이 둘을 나눌 기준이 없었다. 이 문서는 그 기준을 **"동작이 바뀌어도 남는 것 = 개인, 동작에 따라 바뀌는 것 = 동작"** 으로 조작적 정의(operationalize)한다.

---

## 2. 데이터 구조

각 스타일 벡터에 세 개의 라벨을 붙인다.

| 기호 | 의미 | 예 |
|---|---|---|
| $i$ | 사람 (person) | 참가자 A, B, C … |
| $m$ | 동작 종류 (motion type) | 걷기, 뛰기, 손짓, 감정표현 … |
| $r$ | 반복 (repetition) | 같은 사람·같은 동작의 여러 촬영 |

Motion Puzzle이 신체 부위별(팔/다리/척추 등)로 스타일을 뽑으므로, 이하 모든 처리는 **신체 부위 $p$ 별로 독립 수행**하고 마지막에 합친다. (부위별로 정체성이 담기는 정도가 다를 수 있음 — 예: 손짓 스타일은 팔이, 걸음걸이 스타일은 다리가 주도)

---

## 3. 분산 성분 모델 (정의 단계)

각 신체 부위 $p$, 각 스타일 차원 $d$에 대해:

$$
z_{imr}^{(p,d)} = \mu^{(p,d)} + \text{Person}_i^{(p,d)} + \text{Motion}_m^{(p,d)} + (\text{Person}\times\text{Motion})_{im}^{(p,d)} + \epsilon_{imr}^{(p,d)}
$$

혼합효과모형(linear mixed-effects) 또는 이원 분산분석(two-way random-effects ANOVA)으로 다음 분산 성분을 추정한다.

| 성분 | 기호 | 해석 |
|---|---|---|
| 사람 분산 | $\sigma^2_{\text{person}}$ | **개인 고유 성분 — 우리가 원하는 것** |
| 동작 분산 | $\sigma^2_{\text{motion}}$ | 동작-종속 변이 — 제거 대상 |
| 상호작용 | $\sigma^2_{\text{inter}}$ | "이 사람이 이 동작을 할 때만" — 모호, 배제 |
| 잔차 | $\sigma^2_{\text{resid}}$ | 반복 간 노이즈(포즈 추정 오차 포함) |

**개인 고유 signature** = 각 사람의 추정된 Person 효과 (혼합모형의 random-effect BLUP; 실무적으로는 동작 평균을 뺀 뒤의 사람별 균형 중심점).

---

## 4. 차원 신뢰도 가중 (특징 선택 단계)

각 차원 $d$에 대한 ICC:

$$
\text{ICC}^{(p,d)} = \frac{\sigma^2_{\text{person}}}{\sigma^2_{\text{person}} + \sigma^2_{\text{motion}} + \sigma^2_{\text{inter}} + \sigma^2_{\text{resid}}}
$$

- **ICC 높은 차원** → 사람마다 다르고 동작·반복에 흔들리지 않음 → **정체성 축. 유지·가중.**
- **ICC 낮은 차원** → 대부분 동작이거나 노이즈 → **폐기 또는 하향 가중.**

이 단계가 "동작-종속 vs 개인" 분리를 **차원 단위로 직접 수행**한다. 결과적으로 Motion Puzzle 잠재 차원 전체가 아니라 정체성을 담은 부분공간(subspace)만 남는다.

> ICC 계산 규격은 목적에 맞춰 사전 고정할 것 — 여러 반복 측정의 절대 일치도를 보려면 **two-way random, absolute agreement, single measure (ICC(2,1))** 계열이 기본 권장. 최종 선택은 파일럿에서 확정.

---

## 5. 로버스트·균형 집계 (정제 단계)

signature를 만들 때 다음 순서를 지킨다.

1. **동작 내부 먼저 평균** — 사람 $i$·동작 $m$의 반복들을 먼저 평균해 *동작별 중심*을 만든다.
   → 반복 촬영이 많은 동작이 signature를 지배하는 것을 방지.
2. **동작들 사이는 로버스트 추정** — 동작별 중심들을 **기하 중앙값(geometric median)** 또는 **절사평균**으로 합친다.
   → 한 동작에서 우연히 튄 값이 signature를 끌어당기지 못하게 함.
3. **ICC 가중 거리** — 이후 모든 거리·비교는 §4의 ICC를 가중치로 사용(마할라노비스형).

> **이 절차가 기획서 고려사항 #2("정제 실패 시, 특정 동작에서 우연히 두드러진 특성이 identity로 잘못 저장")를 직접 방어한다.** 균형+로버스트 집계는 단일 동작의 아티팩트가 signature에 침투하는 통로를 차단한다.

**산출물:** 사람 $i$의 signature = 정체성 부분공간 안에서 동작-균형·로버스트·ICC가중된 중심점 임베딩. → IP 임베딩 스토어에 저장.

---

## 6. 검증 — Leave-One-Motion-Out 재식별 (**핵심 게이트**)

정제가 정말 "동작에 무관한 개인 특징"을 뽑았는지 증명하는 유일한 경험적 방법.

**프로토콜**
1. 사람마다 signature를 **한 동작 종류를 빼고** 나머지 전부로 만든다. (예: {걷기, 뛰기, 손짓}만 사용)
2. **빠뜨린 동작(예: 감정표현)** 샘플들을 테스트로 사용해, 저장된 모든 사람의 signature와 거리를 잰다.
3. 그 샘플이 **자기 자신의 signature와 가장 가까운지** 확인한다 (재식별 정확도).
4. 빠뜨리는 동작을 바꿔가며 반복하고 평균 낸다.

**해석**
- 안 본 동작에서도 그 사람을 맞힘 → signature가 **진짜 동작 불변**. 정제 성공.
- 못 맞힘 → 그 "identity"는 실은 학습에 쓴 동작들의 아티팩트였음. 정제 실패, §4~5 재조정.

**보고 지표**: 재식별 정확도(rank-1), 자기-signature 거리 vs 타인 거리의 분리 마진, 동작별 편차.

이 테스트가 통과 기준(go/no-go)이며, 교수님 상담에서 방법론의 정당성을 입증하는 핵심 근거다.

---

## 7. 일관성·보정 (ICC 최종 확정 + 샘플 수 결정)

- **최종 ICC**: 완성된 signature에 대해 보류한 반복/동작으로 ICC를 계산, 정량 임계값을 확정한다. (기획서 리스크 "DTW·ICC 임계값 미정" 해소)
- **필요 동작 수 도출**: 동작 종류를 1개→2개→…로 늘리며 ICC(또는 §6 재식별 정확도)가 **평탄해지는 지점**을 찾는다. 이 개선 곡선이 "최소 몇 종류의 동작이 필요한가"에 대한 실험적 답이다.
  - 기획서 가정(ICC 유의성에 최소 5개 샘플, 동작 종류 4~5가지)은 이 곡선으로 검증·조정한다.

---

## 8. 업그레이드 경로 (선형 분해가 부족할 때만)

§3의 선형 분해가 재식별 정확도를 충분히 못 내면(스타일 축이 비선형으로 얽힌 경우), 딥러닝 정제로 격상한다. 데이터·개발 비용이 크므로 **선형 접근을 먼저 확정한 뒤 조건부로만** 진행.

- **A. 대조학습(supervised contrastive)**: 같은 사람·다른 동작 쌍은 당기고, 다른 사람 쌍은 밀어내는 투영 $f$를 학습. 동작 종류는 무시해야 할 nuisance. 사람별 프로토타입 = signature.
- **B. 도메인 적대학습(nuisance removal)**: 임베딩이 *사람 ID는 잘 맞히되 동작 종류는 못 맞히도록*(gradient reversal) 강제 → 명시적으로 "동작 불변·정체성 보존" 임베딩.

두 방법 모두 §6 LOMO를 그대로 평가 게이트로 재사용한다.

---

## 9. 왜 선형 분해부터인가 (설계 근거)

| 근거 | 내용 |
|---|---|
| 현실성 | 대규모 재학습 불필요 → 개발 병목(1인 담당) 완화 |
| 통일성 | 정의·정제·검증이 모두 ICC와 같은 수식 위 → 지표 선택이 사후정당화가 아님 |
| 해석성 | 어느 **신체 부위·차원**이 정체성을 담는지 짚을 수 있음 |
| 방어성 | 혼합효과모형·ICC·LOMO는 심리측정·의학에서 검증된 표준 → 교수 상담에서 정당화 용이 |
| 반증가능성 | LOMO가 실패하면 방법이 틀렸음을 명확히 보여줌 → 좋은 과학 |

---

## 10. 미해결·검증 필요 지점 (정직하게)

- **선형성 가정**: Motion Puzzle 스타일 공간에서 사람/동작 성분이 선형 가법적이라는 보장은 없다 — §3은 검증할 *가설*이며, LOMO 결과가 판정한다.
- **ICC 규격 선택**: ICC(2,1) vs (3,1), single vs average measure 등은 파일럿에서 최종 확정.
- **표본 크기**: 사람 수가 적으면 $\sigma^2_{\text{person}}$ 추정이 불안정 → 사람 수 확보가 동작 수만큼 중요.
- **부위 결합**: 신체 부위별 처리 후 signature를 합치는 가중은 §6 정확도로 튜닝.

## 부록: 전체 흐름

```
동작 샘플별 스타일 벡터 z (부위 p, 사람 i, 동작 m, 반복 r)
        │
        ▼
[3] 분산 성분 분해  → σ²_person / σ²_motion / σ²_inter / σ²_resid 추정
        │            (개인 성분 = 사람 효과)
        ▼
[4] 차원별 ICC → 정체성 축만 선택·가중 (동작·노이즈 축 폐기)
        │
        ▼
[5] 동작 내 평균 → 동작 간 로버스트 집계 → ICC 가중 signature
        │            (동작 아티팩트 침투 차단)
        ▼
[6] Leave-One-Motion-Out 재식별  ── 실패 → [4][5] 재조정
        │  (안 본 동작에서 그 사람을 맞히는가? = 동작 불변 증명)
        ▼ 통과
[7] 최종 ICC 확정 + 필요 동작 수 곡선
        │
        ▼
   IP 임베딩 스토어에 저장 → 재사용
```
