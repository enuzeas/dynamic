# GVHMR로 다시 잰 3D 결과 (2026-10-03)

> 질문: 스타일 전이 비교([style_transfer_compare.md](style_transfer_compare.md))와 동작을 넘는 특징([invariant_traits.md](invariant_traits.md))은 MediaPipe 3D 근사로 쟀다. 더 정확한 3D(GVHMR)로 다시 재도 결론이 유지되나?
>
> 같은 77개 클립(12명의 조깅·걷기·서기·지친 걷기)을 FootMR(GVHMR + 발 접지 보정)로 다시 뽑아 같은 스크립트를 돌렸다. 표의 값은 **MediaPipe / GVHMR** 순서다.

## 1. 요약

1. **"버릇은 동작에 묶여 있다"는 결론은 그대로다.** 조깅에서 뽑아 걷기에 입힌 결과가 실제 걷기를 닮은 정도는 어느 방법도 원래 조깅–걷기 관계를 넘지 못했다(평균 r 0.35, AdaIN 0.36). 팔꿈치는 정확한 3D에서도 넘어가지 않는다(조깅↔걷기 r −0.05 / 0.03).
2. **같은 동작 안의 일관성은 더 높게 잡힌다.** 같은 사람 걷기 두 테이크로 주인을 맞힌 비율이 7/10 → 9/10이다. 허벅지 흔들림은 노이즈로 보였지만(일치도 0.30) 실제로는 일정한 개인 특징이었다(0.78).
3. **같은 동작 전이 순위가 바뀐다.** AdaIN 9/10(기준선과 같음), 모션퍼즐 8/10(MediaPipe에서 4/10), 오프셋 7/10. 오프셋은 허벅지 흔들림을 옮기지 않아 이번엔 뒤진다. AdaIN 권장은 유지되고, 모션퍼즐은 버릴 방법이 아니다.
4. **넘어가는 몸가짐은 4개가 아니라 3개다.** 상체 앞기울기·고개 앞·팔 벌림은 유지되고(r 0.66–0.76), **무릎은 떨어졌다**(0.64 → 0.39). 조깅 무릎은 같은 사람 반복 일관성도 낮게 나와(ICC 0.87 → 0.14) 어느 쪽이 맞는지 아직 모른다. 조깅 → 걷기 식별은 27% → 46%(우연 8%)다.
5. **좌우 비대칭은 이제 잴 수 있다.** 옆모습 걷기에서도 반복 일관성이 높다(상체 옆기울기 0.04 → 0.78, 어깨 높이 차 −0.42 → 0.91). 특히 **좌우 팔 흔들림 비율**(어느 팔을 더 크게 흔드나)이 이동 동작 사이에서 이어진다(조깅↔걷기 −0.11 → 0.79). 동작을 넘는 새 후보다.
6. **측정값 자체가 크게 다른 곳이 있다.** 조깅 팔꿈치 각도는 약 77°로 MediaPipe(107–115°)보다 훨씬 굽게 잡힌다. 정면 촬영에서 팔이 앞뒤로 흔들리는 방향이 깊이 방향이라 MediaPipe가 굽힘을 덜 잡은 것으로 보인다.

## 2. 방법

- **추출:** Colab T4에서 FootMR `tools/demo.py`와 같은 처리를 `gvhmr_colab_batch.py`로 일괄로 돌렸다(`-s` 정적 카메라, `--no_postproc`). 노트북은 [footmr_colab.ipynb](../../footmr_colab.ipynb)와 같은 설치 순서를 따랐다.
  - 입력은 59.94fps → 29.97fps로 2프레임 중 1개만 남겼다. GVHMR은 30fps로 학습됐고 demo.py도 30fps로 간주한다.
  - 렌더링은 건너뛰고 `hmr4d_results.pt`만 남겼다. 77개에 약 4시간 반 걸렸다(클립당 3–4분).
- **변환:** `gvhmr_to_npz.py`가 SMPL-X 순운동학으로 몸 22관절 위치를 구한다(SMPLX_NEUTRAL, 클립 평균 betas). 다시 2배 보간해 MediaPipe와 같은 59.94fps로 맞춘다.
- **분석:** 같은 스크립트를 `POSE_SRC=gvhmr`로 돌렸다. 관절 대응은 MediaPipe와 같은 정의로 맞췄다(골반 = 두 엉덩이 중점, 목 = 두 어깨 중점). SMPL-X 몸 파라미터에는 손가락이 없어 손은 아래팔을 곧게 이은 것으로 뒀다. IK 뼈 방향 오차는 평균 1.03°다.
- **바뀌지 않는 것:** Aberman 2D 입력과 2D 분석(캐리커처, `cross_motion.py`)은 MediaPipe 2D 그대로다.

**동작을 넘는 식별 (자세 특징 9개)**

| | MediaPipe | GVHMR | 우연 |
|---|---|---|---|
| 서기 → 걷기 / 조깅 | 12% / 0% | 19% / 4% | 8% |
| 조깅 → 걷기 | 27% | **46%** | 8% |
| 걷기 → 조깅 | 38% | 38% | 8% |
| 걷기 → 지친 걷기 | 53% | 53% | 9% |
| 조깅 → 지친 걷기 | 47% | 47% | 9% |

- **무릎:** MediaPipe에서 보인 "무릎 굽힘이 넘어간다"는 GVHMR에서 사라진다. GVHMR 조깅 무릎은 반복 일관성도 낮다(0.14). 정면 조깅에서 다리가 깊이 방향으로 짧아 보여 GVHMR 쪽이 불안정할 가능성도 있다. 그래서 무릎은 넘어가는 특징 목록에서 일단 뺀다.
- **팔 흔들림 비:** 왼팔과 오른팔 흔들림 폭의 로그비다. 걷기(옆모습)와 조깅(정면, 원 돌기)은 카메라 방향이 전혀 다른데도 r 0.79로 이어진다. 다만 12명이라 95% 신뢰구간이 대략 0.4–0.9로 넓다.
- **서기:** 전체 식별은 여전히 우연에 가깝다. 다만 가만히 섰을 때의 팔꿈치·팔 벌림은 걷기와 이어진다(0.80, 0.70). 팔을 늘어뜨린 모양이 비슷한 동작끼리는 이어지는 것으로 보인다.
- **비대칭 식별:** 식별에 쓴 정적 비대칭 7개에는 팔 흔들림 비가 들어 있지 않아 식별률은 여전히 낮다(4–20%).

| 같은 동작 전이: AdaIN = 오프셋 > 모션퍼즐 | AdaIN ≥ 모션퍼즐 > 오프셋 |
| 조깅 팔꿈치 평균 약 110° | 약 77°. 정면 조깅의 깊이 방향 각도는 MediaPipe 값을 믿기 어렵다 |

## 7. 한계

- FootMR는 GVHMR에 발 접지 보정을 더한 것이다. 각도 지표에는 영향이 작겠지만 순수 GVHMR과 같지는 않다.
- 12명, 같은 날 같은 옷이다. 지친 걷기 반복은 4명뿐이다.
- 입력을 29.97fps로 줄였다. 각도 평균·범위에는 영향이 작지만 빠른 움직임의 최대값은 조금 깎일 수 있다.
- 두 도구의 관절 정의가 완전히 같지는 않다(MediaPipe 엉덩이 랜드마크와 SMPL-X 엉덩이 관절 위치가 다름). 절대값 비교보다 사람 간 순서·일관성 비교가 의미 있다.
