# 쌤쌤 뷰어 — 캐릭터 교체·화면 저장 다음 할 일

`workthrough.md`(오늘 구현한 코드) 기준, 아직 안 끝난 것 위주. 우선순위 순.

## 1. 서로 다른 캐릭터로 실제 검증 아직 못 함
로컬에 `viewer_data/xbot.fbx` 하나뿐이라, 이번 검증은 같은 파일을 재업로드해 "파이프라인이 에러 없이 도나"만 확인했다. 실제로 몸매·비율이 다른 Mixamo 캐릭터(예: Mixamo에서 다른 캐릭터를 다운받아 옴)로 한 번은 육안 확인이 필요 — 특히 다리 길이 스케일(`hipCfg.scale`, T포즈 방향 정렬)이 극단적으로 다른 체형에서도 안 깨지는지.

## 2. 업로드 캐릭터는 텍스처 없이 단색으로만 보임
`<input type="file">` 하나로는 FBX가 참조하는 외부 텍스처(.fbm 폴더 등) 파일에 접근할 수 없어 `stripUnresolvableTextures()`로 맵을 다 걷어낸다 — 결과물이 기본 색(예: 살구색) 단색 캐릭터로만 보인다. 텍스처까지 살리려면 (a) 폴더째 드래그&드롭을 받아 `.fbm` 폴더를 같이 읽거나, (b) 임베디드 텍스처(FBX 안에 이미지가 통째로 들어간 "Embed Media" 내보내기 옵션)만 지원한다고 안내하는 정도가 현실적. 지금은 스코프 밖.

## 3. 영상 저장 — 길이·해상도가 사용자 조작에 그대로 의존
"🔴 영상 저장 시작"→"⏹ 저장 중지"는 사용자가 직접 누른 구간만큼만 녹화된다. 클립 하나를 정확히 한 바퀴 재생한 분량만 자동으로 담고 싶다면(BVH clip.duration 기준 자동 정지) 추가 구현 필요하지만, 3패널의 clip.duration이 서로 다를 수 있어(콘텐츠/스타일A/스타일B, 또는 콘텐츠/스타일/결과) 어느 패널 기준으로 정지할지부터 결정 필요 — 지금은 요구되지 않아 스코프 밖으로 남겨둠.
