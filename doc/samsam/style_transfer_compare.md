# 스타일 전이 비교 — 동작을 넘어가나, 모션퍼즐 vs 관절 각도 오프셋 (2026-10-01)

> 질문: 참가자 한 사람의 움직임 특징을 latent 공간에 넣어 **다른 동작**에도 입힐 수 있나? 9/29 회의에서 이태희 연구원은 "조깅에서 뽑은 특징은 조깅 계열에만 유효하다"고 했다. 이를 우리 데이터로 확인하고, 두 방법(모션퍼즐, 관절 각도 오프셋)을 같은 기준으로 비교했다.
>
> 비교 페이지: https://claude.ai/artifact/Awpnow3Y4diU8g4Ev8tGWo (비공개, 공유 메뉴에서 열어야 팀원이 볼 수 있음). 모션퍼즐·Aberman 2020(3D/2D)·관절 각도 오프셋을 함께 비교한다.

## 1. 요약

> **(2026-10-01 추가)** 관절 각도 AdaIN을 더해 비교했다. 같은 동작에서 뽑으면 AdaIN이 오프셋과 같은 최상위(식별 80%, 상관이 같은 사람 두 테이크 수준)이고 팔·허벅지 흔들림은 더 잘 옮긴다 — §5a.

1. **사람마다 다른 움직임 특징은 대부분 동작마다 따로다.** 조깅에서 팔을 펴고 뛴 사람이 걸을 때도 팔을 펴지는 않았다(팔꿈치 조깅↔걷기 상관 2D 0.26, 3D −0.05). 조깅 프로필로 걷기 영상의 주인을 맞히는 비율은 우연 수준이다(12%, 우연 8%). 팔 벌림·무릎·고개는 일부 넘어간다(0.55–0.68). 이태희 연구원의 말이 맞다.
2. **두 방법 모두 조깅 특징을 걷기로 옮기기는 한다.** 사람 간 순서가 결과에 그대로 남는다(평균 상관 오프셋 0.78, 모션퍼즐 0.83). 결과만 보고 원천 조깅의 주인을 맞히는 비율도 오프셋 67%, 모션퍼즐 83%다.
3. **하지만 결과가 그 사람의 실제 걷기를 닮지는 않는다.** 결과와 실제 걷기의 상관은 오프셋 0.32, 모션퍼즐 0.19로, 원래 조깅과 걷기 사이 상관(0.40)보다도 낮다. 모션퍼즐은 개인 특징과 함께 "조깅다움" 자체(팔을 굽히고 크게 흔들기)까지 걷기에 옮긴다. 예: P001은 팔꿈치 −31°, 팔 흔들림 +36°.
4. **같은 동작(걷기)에서 특징을 뽑으면 결과가 실제 걷기를 거의 그대로 닮는다.** 걷기 첫 테이크로 뽑아 입힌 결과를 스타일 뽑을 때 쓰지 않은 두 번째 테이크와 비교했다(10명).
   - 오프셋: 팔꿈치·무릎·팔 벌림·상체·팔 흔들림 상관 0.82–0.96으로, 같은 사람이 두 번 걸은 일치도(상한)와 같다. 식별 80%(우연 10%).
   - 모션퍼즐: 상관 0.74–0.95, 식별 40%.
5. **결론: 캐릭터에 입힐 동작과 같은 종류의 동작을 찍어야 한다.** 조커가 걷는 장면이면 참가자의 걷기를 찍는다. 두 방법 중에서는 같은 동작 조건에서 **관절 각도 오프셋이 더 정확했다**. 무엇을 바꿨는지 정확히 알 수 있다는 장점도 있다. 모션퍼즐은 리듬처럼 오프셋이 다루지 못하는 성분까지 옮길 수 있는 대신, 결과가 원천에서 더 흐트러진다.

## 2. 방법

- **교차 동작 검증(2D, `cross_motion.py`):** 12명의 조깅(M06)·걷기(M01)·지친 걷기(M07)에서 크기와 무관한 각도 6개(팔꿈치, 무릎, 팔 벌림, 허벅지 들기, 상체 기울기, 고개)를 쟀다.
  - 동작 안 반복 ICC, 동작 사이 상관, 동작을 넘는 식별률을 계산했다.
  - 비교용으로 팔다리 길이 비율(체형)도 쟀다.
- **참가자 3D(`mp3d_extract.py`):** MediaPipe world landmarks를 썼다. 골반 중심·미터 단위다. 루트 이동은 2D 위치와 몸통 길이 변화로 추정했다. GVHMR(GPU)보다 거칠지만 로컬 CPU로 바로 얻을 수 있다.
- **3D → CMU BVH:** 뼈 방향을 맞추는 IK(`style_compare.ik`)로 만들었다. 몸통은 골반 좌우선과 어깨선으로 방향을 잡았다.
  - 팔다리 뼈 방향 오차는 0°, 전체 평균 0.87°다.
  - CMU 배우 골격 비율에 얹으므로 체형은 빠진다.
- **콘텐츠:** CMU 35_06(기본 걷기, 1.1 m/s).
- **방법 A, 모션퍼즐:** `external/motion_puzzle/test.py`. content = 35_06, style = 참가자 BVH. 발 미끄럼 보정판(`_fixed`)을 썼다.
- **방법 B, 관절 각도 오프셋:** 참가자의 원천 동작이 12명 평균과 다른 만큼 콘텐츠에 더했다.
  - 팔꿈치·무릎(펴는 쪽), 팔 벌림(바깥쪽), 상체 숙임(앞쪽)을 각도로 더한다.
  - 팔 흔들림은 앞뒤 각을 평균 둘레로 배율만큼 키운다.
  - 관절 위치를 회전으로 고친 뒤 같은 IK로 BVH를 만든다. 확인 결과 지시한 각도대로 바뀌었다(팔꿈치 +20° → +18°, 180° 근처에서 잘림).
- **평가 지표(3D 각도 6개):** 팔꿈치, 무릎, 팔 벌림, 상체 숙임, 팔 흔들림 범위, 허벅지 흔들림 범위.

## 5a. 관절 각도 AdaIN (2026-10-01 추가)

MOCHA(SIGGRAPH Asia 2023, 장덕경·이성희 등)가 학습된 특징에 쓰는 AdaIN을 **사람이 읽는 관절 각도 16채널**에 직접 적용했다. 채널은 상체·고개의 앞뒤/옆 기울기, 위팔·허벅지의 앞뒤/옆 각(몸통 좌표계), 팔꿈치·무릎 굽힘이다.

c'(t) = μ_스타일 + (σ_스타일 / σ_콘텐츠) · (c(t) − μ_콘텐츠)

- 콘텐츠 걷기의 평균·흔들림 폭을 지우고 참가자의 것을 입힌다. "각도 오프셋 + 팔 흔들림 배율"을 모든 채널로 넓힌 일반형이다.
- **옆 방향 채널은 평균만 옮긴다.** 참가자가 카메라 앞을 가로질러 걸어서 몸의 옆 방향이 카메라 깊이 방향이 된다. 그대로 옮기면 깊이 추정 노이즈가 흔들림으로 붙는다(상체 옆 흔들림 1.0° → 8.0°).
- **확인:** 채널 → 관절 위치 → 채널 왕복 오차 0°, 목표 평균·흔들림 정확히 재현.
- "AdaIN상대"는 참가자 절대값 대신 집단 평균 대비 차이만 옮긴 판이다.

**걷기 → 걷기 (10명, 안 쓴 테이크 T02와 비교)**

| 상관 r | 팔꿈치 | 무릎 | 팔 벌림 | 상체 숙임 | 팔 흔들림 | 허벅지 흔들림 | 식별 |
|---|---|---|---|---|---|---|---|
| 상한 (같은 사람 T01↔T02) | 0.93 | 0.82 | 0.90 | 0.96 | 0.89 | 0.30 | 70% |
| **관절 AdaIN** | **0.93** | **0.82** | **0.90** | **0.96** | **0.94** | 0.10 | **80%** |
| 각도 오프셋 | 0.93 | 0.82 | 0.88 | 0.96 | 0.89 | −0.52 | 80% |
| AdaIN상대 | 0.93 | 0.82 | 0.70 | 0.96 | 0.94 | 0.24 | 60% |
| 모션퍼즐 | 0.90 | 0.86 | 0.86 | 0.95 | 0.74 | −0.11 | 40% |
| Aberman 3D / 2D | ≈0 | | | | | | 10% / 10% |

**조깅 → 걷기:** AdaIN도 다른 방법처럼 조깅 특징은 옮기지만(평균 r 0.87), 실제 걷기와는 닮지 않는다(0.39, 원래 조깅↔걷기 0.40과 같은 수준). 동작이 다르면 어떤 방법도 그 사람의 걷기를 만들지 못한다.

**결론:** 관절 AdaIN이 오프셋과 같은 최상위이고, 팔 흔들림(0.94)과 허벅지 흔들림에서 더 낫다. 16채널 전부를 옮기므로 6개 지표 밖의 습관(고개, 옆 기울기 평균 등)도 함께 옮겨진다. 학습이 필요 없고, 배율을 곱해 캐리커처로 키우기도 그대로 된다.

## 5b. 추가 모델: Aberman et al. 2020 (deep-motion-editing)

"Unpaired Motion Style Transfer from Video to Animation"(SIGGRAPH 2020)이다. 같은 CMU 31관절 골격을 쓰고, 스타일을 3D BVH나 **영상의 2D 관절(OpenPose JSON)**로 받는다. 2D 입력은 3D 추정을 거치지 않아도 되므로, MediaPipe 2D를 BODY_25로 바꾸고 학습 데이터(트레드밀 영상)와 몸통 크기를 맞춰 넣었다. 실행은 1건당 약 3초다.

| | 조깅→결과 (특징 옮김) | 결과↔실제 걷기 | 걷기→걷기, 결과↔T02 | 식별(원천 / 실제 걷기) |
|---|---|---|---|---|
| Aberman 3D | 평균 r 0.10 | −0.08 | 0.03 | 0% / 0% |
| Aberman 2D | 평균 r 0.26 | 0.18 | −0.09 | 17% / 17% |

- **우리 데이터에는 맞지 않는다.** 결과가 원천의 사람 간 순서를 지키지 못하고, 상체 숙임 16–34°, 팔 흔들림 56–135°처럼 크게 과장된 동작을 만든다.
- **원인은 학습 데이터로 보인다.** 배우가 연기한 8가지 감정 걸음(Xia 데이터: 화남·노인·우울 등)으로 학습해서, 미묘한 개인차를 그 감정 스타일 중 하나 쪽으로 끌어간다.
- **확인 실험:** 스타일로 기준 걷기 자신(35_06)을 넣어도 원본이 재현되지 않았다(상체 −2° → 12°, 팔 흔들림 16° → 49°). Xia 학습 데이터의 "neutral"을 넣어도 비슷했다. 우리 입력 형식의 문제가 아니라 모델이 만드는 기본 동작 자체가 다르다는 뜻이다.

## 6. 한계

- 참가자 3D는 MediaPipe 추정이라 거칠다. GVHMR로 다시 하면 숫자가 바뀔 수 있다. 특히 걷기는 옆으로 걸어 정면 카메라에서 깊이 추정이 약하다.
- 지표는 각도 6개뿐이다. 리듬·타이밍(언제 팔을 흔드나)은 재지 않았고, 오프셋 방법은 이를 옮기지도 못한다. 모션퍼즐의 장점이 여기서 드러날 수 있는데 이번 평가에는 잡히지 않는다.
- 12명(걷기 비교 10명), 같은 날 같은 옷이다.
- 콘텐츠 걷기 하나(CMU 35_06)만 썼다. 평가는 숫자 기준이고, 눈으로 본 판단은 비교 페이지에서 해야 한다.

## 7. 제안

1. **촬영:** 캐릭터에 입힐 동작과 같은 동작을 찍는다. 시연이 "걸어오는 동작"이면 참가자의 걷기를 2–3번 찍는다.
2. **방법:** 1차는 관절 각도 오프셋(+ 팔 흔들림 배율)으로 간다. 정확하고 설명이 쉽고, 캐리커처 배율(×1.5, ×2.5)을 곱하기도 쉽다. 리듬 같은 성분이 필요하면 모션퍼즐을 덧붙이는 혼합을 검토한다.
3. **3D:** 데모 품질이 필요하면 GVHMR(Colab)로 같은 비교를 다시 해서 MediaPipe 결과와 맞는지 본다.
