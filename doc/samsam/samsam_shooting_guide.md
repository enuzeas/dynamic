# 쌤쌤 촬영 가이드 (2026-07-15)

> 목적 한 줄: **동작별로 스타일을 나눠 찍는 게 아니라, 한 사람의 "스타일"을 안정적으로 뽑아내기 위해 여러 동작을 다양하게 찍는다.** 근거: `samsam_plan.md` 2절 스파이크 결과 — 스타일 하나를 여러 다른 동작에 재사용하는 게 기술적으로 확인됨. 여러 동작을 찍는 이유는 "동작마다 다른 스타일을 쓰기 위해서"가 아니라 "그 사람 특유의 리듬·무게중심을 우연한 한 동작의 특징과 헷갈리지 않기 위해서"다.

---

## 1. 촬영 셋업

| 항목 | 기준 | 이유 |
|---|---|---|
| 카메라 | 고정(삼각대 또는 고정된 곳에 거치), 이동/줌 금지 | 흔들리면 관절 위치 오차가 늘어남 |
| 거리/구도 | 전신이 프레임 안에 항상 들어오게, 여유 공간 확보 | 팔다리가 잘리면 그 프레임은 못 씀 |
| 해상도 | 1080p 이상 | 관절 추정 정확도 확보 |
| 프레임레이트 | 60fps 권장(최소 30fps) | 리듬·타이밍이 스타일의 핵심 신호라 fps가 낮으면 그게 뭉개짐 (`motion_value_assessment.md` 9장) |
| 조명 | 밝고 고른 조명, 역광 금지 | 실루엣만 보이면 관절 추정 실패 |
| 배경 | 단순할수록 좋음(사람과 겹치는 물체 없이) | 배경이 복잡하면 포즈 추정 오류 증가 |
| 의상 | **몸에 붙는 옷** — 헐렁한 옷·긴 치마·후드 금지 | 헐렁한 옷은 관절 위치를 가려서 오차를 키움 (동일 문서 9장) |
| 신발 | 발이 잘 보이는 신발(발가락 안 가려지게) | footskate 판정에 발 관절이 중요 |

---

## 2. 찍을 동작 리스트 (한 사람당)

"다양성이 양보다 중요"(`samsam_worksheet.md`) 원칙에 따라, 아래처럼 **서로 다른 종류의 동작**을 고루 찍는다. 각 동작 10~20초, 1~2테이크면 충분 — 같은 동작을 5번씩 반복할 필요는 없다(그건 이전 식별 트랙의 기준이었고, 스타일 캡처는 반복 횟수보다 동작 종류의 다양성이 중요).

| # | 동작 | 비고 |
|---|---|---|
| 1 | 평소 속도로 걷기 (왕복) | 가장 기본, 리듬·보폭의 기준선 |
| 2 | 빠르게 걷기 또는 가볍게 뛰기 | 속도가 달라져도 유지되는 특징 확인 |
| 3 | 쪼그려 앉기 → 일어서기 | 무게중심 이동 습관 |
| 4 | 바닥/낮은 곳 물건 줍는 동작 | 몸을 굽히는 방식 |
| 5 | 서서 자연스럽게 손짓하며 말하기 (내용 무관, 제스처만) | 상체·팔 스타일 |
| 6 | 인사하기 (가벼운 목례 또는 손 흔들기) | 짧고 반복 가능한 제스처 |
| 7 | 앉아서 졸거나 피곤한 티 내기 | 감정·피로 상태의 자세 변화 |
| 8 | (선택) 기쁘거나 신난 상태 표현 동작 | 감정이 실린 동작의 차이 확인 |

**약속하는 범위:** 위 동작들에서 잡히는 건 전신 리듬·보폭·무게중심·큰 관절(어깨·골반·무릎) 협응까지다. 손가락 세부 동작이나 미세한 표정은 이 촬영 셋업(단안 카메라)으로는 범위 밖 — 무리해서 잡으려 하지 않는다.

---

## 3. 인당 예상 소요 시간

동작 8종 × (촬영 10~20초 + 준비/재촬영 여유) ≈ **1인당 15~20분**. 8~12명 촬영 시 팀 전체로 반나절 안에 가능한 규모.

---

## 4. 파일 저장 규칙

`{이름}_{동작번호}_{동작명}.mp4` 형식으로 저장. 예: `한우진_01_걷기.mp4`, `한우진_07_졸기.mp4`.
동작번호는 위 표의 번호를 그대로 사용 — 나중에 어떤 동작인지 파일명만 보고 바로 알 수 있게.

---

## 5. 촬영 전 동의 체크 (건너뛰지 않기)

- 촬영 대상자에게 **무엇에 쓰이는지**(캡스톤 프로젝트, 스타일 캡처 실험) 설명하고 구두/서면 동의를 받는다.
- 언제든 **철회 가능**하다는 것을 알린다.
- 움직임 데이터는 생체정보로 분류될 수 있는 민감 정보다(`personal.md` 참고) — 캡스톤 검증 목적 외 재배포·공개 금지를 원칙으로 한다.
- 세부 동의서 양식·법적 요건은 팀에서 아직 확정 안 됨 — 확정 전까지는 이 원칙만 지키고 촬영 규모를 크게 벌리지 않는다.

---

## 6. 촬영 중 자가 체크리스트

- [ ] 카메라가 흔들리지 않고 고정돼 있는가
- [ ] 전신이 매 프레임 잘리지 않고 들어오는가
- [ ] 조명이 충분하고 역광이 아닌가
- [ ] 옷이 몸에 붙는 옷인가
- [ ] 8개 동작을 다 찍었는가
- [ ] 파일명 규칙대로 저장했는가
