# 데모 산출물 분석 결과

분석 대상:

1. `demo_output.png`
2. `Figure_1.png`
3. `homeostasis_matlab.png`

## 1. demo_output.png 분석

`demo_output.png`는 오른손목 속도 곡선(프레임마다 손목이 얼마나 빠르게 움직였는지 나타낸 선)을 반복별로 시각화한 결과이다.

상단의 A, B 반복 그래프를 보면 각 반복 곡선이 같은 모양으로 안정적으로 겹치지 않는다. 피크(속도가 가장 크게 튀는 봉우리)의 위치와 높이가 반복마다 크게 달라서, 같은 동작을 반복했을 때 나타나야 하는 항상성(같은 사람이 같은 동작을 했을 때 패턴이 비슷하게 유지되는 성질)은 약하게 나타난다.

하단의 평균 속도 곡선(반복 여러 개를 평균낸 대표 곡선) 비교에서는 A와 B의 평균 곡선이 일부 구간에서 다르게 보인다. 그러나 두 곡선 모두 내부 변동 폭이 크고, 표준편차(반복들이 평균에서 얼마나 흩어져 있는지 나타내는 값) 영역도 넓다. 따라서 이 그래프만으로는 "두 사람의 고유한 다이내믹스 서명(개인의 움직임 리듬과 속도 변화 패턴)이 명확히 분리된다"고 강하게 말하기 어렵다.

요약하면, 이 그림은 움직임 속도 패턴에 개인차(사람 사이의 차이) 또는 반복차(같은 사람이 반복할 때 생기는 차이)가 존재할 가능성은 보여주지만, 반복 안정성(반복할수록 비슷하게 나오는 정도)은 아직 충분하지 않다.

## 2. Figure_1.png 분석

`Figure_1.png`는 DTW 거리 행렬, genuine/impostor 거리 분포, FAR/FRR 곡선을 보여준다.

DTW(Dynamic Time Warping, 길이나 타이밍이 조금 다른 두 곡선을 맞춰 비교하는 방법) 거리 행렬(샘플끼리 얼마나 다른지 표로 나타낸 것)에서는 같은 라벨(같은 그룹 이름) 내부의 거리와 다른 라벨 간 거리가 어느 정도 구분되는 경향이 보인다. 거리 분포에서도 genuine(같은 사람 또는 같은 그룹끼리 비교한 경우) 거리와 impostor(다른 사람 또는 다른 그룹끼리 비교한 경우) 거리의 중심이 완전히 같지는 않다.

수치 결과는 다음과 같다.

- Rank-1 Accuracy(가장 가까운 샘플 하나가 같은 그룹인지 보는 식별률): 100%
- EER(FAR와 FRR이 같아지는 지점의 오류율): 13.9%
- genuine DTW 평균: 0.8939
- impostor DTW 평균: 1.0131

Rank-1 Accuracy만 보면 가장 가까운 샘플을 찾는 단순 식별은 성공했다. 하지만 EER 13.9%는 오차가 아직 남아 있다는 뜻이다. FAR(False Acceptance Rate, 다른 사람인데 같은 사람으로 잘못 받아들이는 비율)와 FRR(False Rejection Rate, 같은 사람인데 다른 사람으로 잘못 거부하는 비율)을 함께 보면 인증 시스템의 오류 균형을 확인할 수 있다. 특히 샘플 수가 6개뿐이므로, 이 결과는 "가능성 확인" 수준이지 일반화 가능한 성능 지표는 아니다.

## 3. homeostasis_matlab.png 분석

`homeostasis_matlab.png`는 항상성을 ICC와 평균 반복상관으로 요약한 그래프이다.

측정값은 다음과 같다.

- A: ICC(Intraclass Correlation Coefficient, 같은 그룹 내부 반복값이 얼마나 일관적인지 보는 지표) 0.0501, 평균 반복상관(반복 곡선끼리 서로 얼마나 비슷한지 보는 평균 상관계수) 0.0465
- B: ICC 0.0733, 평균 반복상관 0.0781

두 값 모두 기준선 0.5보다 훨씬 낮다. 이는 같은 조건에서 반복한 움직임이 안정적으로 재현되지 않았다는 뜻이다. 따라서 현재 데이터에서는 항상성 증거가 약하다.

## 종합 결론

현재 산출물은 오른손목 속도 기반 다이내믹스 서명이 사람 또는 반복 조건에 따라 달라질 수 있음을 보여준다. 특히 DTW 기반 식별(곡선 간 거리를 이용해 어느 그룹에 가까운지 판단하는 방식)에서는 A/B 그룹이 어느 정도 분리되는 결과가 나온다.

하지만 가장 중요한 한계는 항상성이 낮다는 점이다. 같은 사람의 반복 곡선이 안정적으로 겹치지 않으면, 이후에 다른 사람과의 차이를 보더라도 그것이 개인 고유성인지 단순 반복 오차인지 구분하기 어렵다.

따라서 현재 결과의 적절한 해석은 다음과 같다.

> 오른손목 속도 곡선에는 구분 가능한 패턴 차이가 존재하지만, 현재 촬영/정렬 조건에서는 반복 항상성이 충분히 확보되지 않았다.

## 다음 개선 방향

1. 움직임 시작 지점을 자동 감지해 모든 반복을 같은 기준점으로 정렬한다.
2. 팔을 들기 전 정지 구간과 동작 종료 후 정지 구간을 짧게 포함해 촬영한다.
3. 같은 사람 3회와 다른 사람 3회를 분리해 다시 측정한다.
4. 오른손목 하나만 보지 말고 오른팔꿈치, 오른어깨 속도까지 함께 사용한다.

현재 단계에서는 논문용 최종 결과라기보다, 데모용 예비 실험 결과로 보는 것이 적절하다.
