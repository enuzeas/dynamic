원천데이터 실행 계획서 — 유튜브 안무 영상 + 직접 촬영

0. 전제
이 계획서는 thesis.md의 핵심 명제(층위 1: 고유성 + 항상성)를 scope.md의 3개월 MVP 기준(rank-1 accuracy, EER, ICC)으로 검증하는 것을 목표로 하며, 원천데이터를 "유튜브 안무 영상"과 "직접 촬영"으로 이원화한다는 조건 위에서 다시 짠 실행안이다. 두 소스는 서로 대체재가 아니라 검증하는 명제가 다른 상호보완재로 쓴다.

1. 데이터 소스 역할 분담

| 소스 | 검증하는 것 | 강점 | 한계 |
|---|---|---|---|
| 직접 촬영 | 항상성(1b) — 같은 사람 반복 시 일관성. MVP 핵심 지표(rank-1/EER/ICC) 1차 산출 | 시작 신호·프레임레이트·조명·카메라 거리 통제 가능. 저크까지 믿을 수 있는 정밀도 확보 | 표본 확보에 시간·인력 소요. n=8–12명이 한계 |
| 유튜브 안무 영상 | 고유성(1a) 대규모 검증 + groupdance.md의 자연실험(안무 통제된 조건에서 다수 퍼포머 비교) + 군무 항상성(솔로 등록→군무 매칭) | 같은 안무를 수십~수백 명이 이미 올려둔 상태라 n을 적은 비용으로 확장 가능 | 압축·컷 편집·카메라 무빙·프레임레이트 불균일로 저크 등 고차 미분 특징엔 노이즈 큼. 촬영 조건 통제 불가 |

원칙: 정밀 신호(저크 포함 다관절 특징)는 직접 촬영에서, 통계적 규모(다수 표본으로 구별력 검증)는 유튜브에서 확보한다. 두 소스를 같은 정밀도로 취급해 하나의 분포로 섞지 않는다 — 섞으면 노이즈 원인이 촬영 조건 때문인지 사람 때문인지 구분이 안 된다.

2. 리스크와 완화책

법적·윤리적 리스크 (personal.md 연장)
- 생체인식정보는 개인정보보호법상 민감정보다. 유튜브 영상 속 인물은 동의 없이 이 프로젝트의 생체 특징 추출 대상이 된다.
- 완화책: (1) 라이선스가 명확한 채널(공식 안무 튜토리얼, CC 라이선스, 크리에이터 동의 확보된 클립) 우선 사용. (2) "이 영상이 누구인지"가 아니라 "두 영상이 같은 사람인지"만 보는 익명 비교 설계 유지 — 신원 DB에 실명을 매핑하지 않는다. (3) 상업적 재배포·재학습용 데이터셋 공개 금지, 캡스톤 검증 목적으로 범위를 좁혀 문서화. (4) 최종 활용 전 법률 자문(성진구 담당 영역) 필수 — 적합성 판단은 여기서 내리지 않는다.

데이터 품질 리스크
- 유튜브 영상은 압축·편집컷·줌·프레임레이트 불균일이 섞여 미분 기반 특징(속도→가속도→저크로 갈수록)에 노이즈가 증폭된다.
- 완화책: 유튜브 데이터는 저크 같은 고차 미분 특징을 배제하고 속도 수준 특징 위주로 사용. 컷 편집이 있는 구간은 자동 컷 감지로 제외. 프레임레이트는 공통 기준(예: 30fps)으로 리샘플링 후 사용.

3. 파이프라인 보완 사항 (이전 진단 반영)
- 정렬 방식 통일: rank-1(DTW 기반)과 ICC(현재 시작점 정렬)가 서로 다른 정렬 기준을 쓰고 있어 "AI 정답률은 높은데 일관성은 낮다"는 역설이 발생했다. 두 지표 모두 DTW 정렬 결과 위에서 계산하도록 통일한다.
- 노이즈 필터링: 관절 좌표에 Savitzky-Golay 스무딩을 적용한 뒤 미분한다. 특히 저크는 필터링 없이는 신호보다 노이즈가 커진다.
- 다관절 확장: 손목 단일 관절 속도 → 손목+팔꿈치+어깨(필요 시 몸통) 다관절 특징 결합. scope.md MVP 스펙(6–8개 관절)과 정합.
- Enrollment/verification 분리: 현재 9개 클립을 서로 leave-one-out 비교하는 방식에서, 등록(반복 N-1회)-검증(나머지 1회) 구조로 바꿔 EER을 표준 방식으로 산출한다.

4. 단계별 실행 계획 (scope.md 월별 체크포인트에 유튜브 소스 도입 시점을 얹은 개정판)

Phase 0 — 착수 전 (즉시)
데이터 거버넌스 확정: 유튜브 소스 선정 기준(라이선스), 직접 촬영 동의서 템플릿, 익명 비교 설계 원칙을 문서로 고정한다. 담당: 성진구.

Phase 1 — 6월, MVP 데이터 구축
직접 촬영 우선 진행: 8–12명, 동작 2–3종, 인당 5회 반복, 시작 비프음·고정 카메라·조명 통제. 유튜브는 이 시점에 파일럿으로 3–5개 클립만 확보해 파이프라인이 압축·편집 노이즈에 얼마나 민감한지 사전 진단한다. 담당: 이한성(수집), 박세준(파이프라인).

Phase 2 — 7월, 파이프라인 정비
3번 보완 사항(정렬 통일·스무딩·다관절·enrollment 분리) 적용. 직접 촬영 데이터로 1차 rank-1/EER/ICC 산출. 담당: 박세준.

Phase 3 — 8월, MVP 판정
핵심 명제(고유성+항상성) 통과 기준 도달 여부를 확정한다. 통과 시 Phase 4로, 미달 시 촬영 조건 또는 특징 설계를 재점검하고 재수집한다. 이 관문을 건너뛰지 않는다 — scope.md가 명시한 "3개월 MVP가 통과 기준"이라는 순서를 그대로 따른다.

Phase 4 — 9월, 유튜브 데이터 스케일업 + 군무 항상성
라이선스 확인된 채널에서 동일 안무 다수 퍼포머 클립을 n=30–50 목표로 수집해 고유성 지표를 대규모로 재검증한다. 동시에 groupdance.md 설계대로 "솔로로 등록한 서명이 군무 속 같은 인물을 찾아내는가"를 오클루전이 적은 유튜브 군무 클립으로 시도한다. 담당: 이한성(소싱), 박세준(검증).

Phase 5 — 10–11월, 결과 통합
직접 촬영(정밀 신호)과 유튜브(대규모 구별력) 결과를 하나의 보고서로 통합하고, 두 소스 간 지표 차이 자체를 "촬영 조건이 신호 품질에 미치는 영향"이라는 부가 발견으로 정리한다. 발표 자료·문서화. 담당: 전원.

5. 성공 기준 (scope.md와 동일하게 유지)
rank-1 accuracy, EER, ICC 세 숫자로 판정한다. 이 세 숫자가 나오면 핵심 명제(층위 1)가 서고 발표 방어가 가능하다는 scope.md의 기준을 그대로 따르며, 이번 계획서는 그 숫자를 "어떤 데이터로, 어떤 순서로" 만들어낼지를 구체화한 것이다.

6. 매핑 요약
직접 촬영 = 항상성 정밀 검증의 1차 데이터. 유튜브 안무 영상 = 고유성의 규모 확장 + 군무 항상성(콘텐츠 완전 통제 자연실험)의 원천. 두 소스를 같은 실험에 동일 정밀도로 섞지 않고, 각자의 강점이 맞는 명제에만 투입한다.
