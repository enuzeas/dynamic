# GPU 필요 작업 정리 (2026-08-01)

> 목적 한 줄: 파이프라인 단계별로 GPU가 **필수인지 선택인지**를 명확히 정리한다. "이 프로젝트에 GPU가 필요 없다"는 식의 과잉 일반화를 막기 위한 문서 — 실제로는 단계마다 다르다.

---

## 1. 단계별 GPU 필요 여부

| 단계 | GPU 필요? | 근거 |
|---|---|---|
| 영상 → 3D 스켈레톤(GVHMR + FootMR) | **필수** | CUDA+Linux 전용(pytorch3d 휠) — Mac 로컬 자체가 불가능. Google Colab 무료 T4로 실행 중(`samsam_plan.md` 28행). 이 프로젝트에서 **유일하게 피할 수 없는 GPU 병목** |
| hmr4d_to_npz.py / retarget_smpl_to_cmu.py | 불필요 | 순수 배열 변환(CPU, `torch`는 텐서 연산용일 뿐 학습 없음) |
| Motion Puzzle 스타일 전이(`test.py`) | 선택 | 코드에 `torch.device('cuda' if torch.cuda.is_available() else 'cpu')` — CPU 폴백 내장. GPU 없으면 실측 ~9초/쌍이 더 늘어나는 정도 |
| CMU→Mixamo 리타겟, three.js 뷰어 | 불필요(딥러닝 GPU 기준) | 결정론적 회전 공식 + 브라우저 WebGL 렌더링 — 그래픽카드가 쓰이긴 하지만 "딥러닝 학습/추론용 GPU"와는 다른 용도 |
| 개인 고유 특징 정제 임베딩 학습 — **팀 자체 데이터(8~12명)만** | 선택 | 모델(ST-GCN 등)과 데이터 양 모두 작아 CPU로도 현실적 시간 안에 학습 가능 |
| 위 임베딩의 **대규모 사전학습**(NTU RGB+D 등) | **사실상 필요** | 모델 자체는 가볍지만 데이터 규모가 커지면 CPU 학습 시간이 비현실적으로 늘어남 |

---

## 2. 헷갈리기 쉬운 지점

"GPU 필요 없다"는 얘기가 나온 건 **정제 단계 하나**, 그것도 "팀이 직접 찍은 소규모 데이터로만 학습하는 경우"라는 조건이 붙은 얘기였다. 이걸 프로젝트 전체로 일반화하면 안 된다 — 영상→스켈레톤 단계(GVHMR+FootMR)는 처음부터 끝까지 GPU 필수이고, 이게 바뀐 적은 없다.

---

## 3. 결론 — 자원을 어디에 써야 하는가

- **꼭 필요**: GVHMR+FootMR용 GPU 1대(Colab 무료 T4로 지금 충분). 대규모 사전학습을 하기로 하면 그 학습에도 GPU 필요.
- **있으면 좋음**: Motion Puzzle 추론, 팀 자체 데이터 정제 학습 — 없어도 되지만 있으면 빠름.
- **T4 2대의 실제 효과**: `samsam_gpu_time_estimate.md` 참고 — 영상 1개 처리 속도는 안 빨라지고, 영상 여러 개를 동시 처리할 때 총 시간이 절반으로 줄어듦.
